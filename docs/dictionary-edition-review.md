# dictionary editions change the mechanical constraint

Method update: October 18, 2026.

The noun list is part of the deck's rules. Adding one noun anywhere in the list moves the +7 target of the seven nouns just before it (the walk wraps around), and in the current deck that can change up to six of the eight cards even though no card file changes. Sorting the list for neatness is therefore a content change with a larger effect than its diff suggests.

Before changing the dictionary, retain its ordered edition and produce a mechanical comparison of the eight base lines under the old and proposed order. List the changed substitutions, wraparound cases and unchanged words. A deterministic rerun should use the same card input and the exact same ordered list. A dictionary hash can identify an edition, while the human review still decides whether the changed constraint is useful.

The author reviews any affected vignette by hand and checks its word window. This refresh adds no card or vignette and gives no model authorship role. The next acceptance exercise should change one noun in a temporary copy, inspect the affected substitutions and restore the original input. The static print artifact stays the product.
